# merrittmason.com

Personal site. Next.js (App Router) + React + TypeScript + Tailwind v4.

- `content/profile.md` — source of truth for all site copy and data
- `content/assets/` — headshot, portraits, resume, favicon source
- `public/` — served static files (resume PDF, favicon)

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run lint
```
